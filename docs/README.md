# Documentation

| Path | What to put here |
|---|---|
| `architecture/` | Architecture diagram, component and sequence diagrams, tech decisions. `ocr-and-refills.md` covers OCR, refill prediction, adherence and analytics |
| `database/` | ER diagram, schema description, migration notes |
| `api/` | Endpoint reference, request/response examples, Postman collection export |
| `wireframes/` | UI wireframes and screen flows (Milestone 1 deliverable) |
| `milestones/` | One report per milestone — templates are already in place |
| `demo/` | Demo script, screenshots, link to the recorded walkthrough |
| `reports/` | [Testing](reports/testing-report.md), [performance](reports/performance.md), [OCR](reports/ocr-evaluation.md) and [refill](reports/refill-evaluation.md) evaluations, [final report](reports/final-report.md) |
| `deployment.md` | How to deploy: Docker Compose (tested), Render, AWS, Azure; environment variables; operations |

Milestone reports are checked by CI. Fill in the template that matches the milestone
you are submitting, on your own branch.
