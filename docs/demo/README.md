# PillSync Demo

## Demo status

The application is prepared for deployment, but a live deployment URL has not yet been recorded.

## Demonstration flow

### Patient

1. Sign in.
2. Open the patient dashboard.
3. View or add medications.
4. View reminders and notifications.
5. Record medication doses.
6. Review adherence/history.
7. Review refill information.

### OCR

1. Open prescription scanning.
2. Upload a prescription image.
3. Run OCR processing.
4. Review extracted medication information.
5. Review validation and low-confidence handling.

### Caregiver

1. Sign in as a caregiver.
2. Open the caregiver dashboard.
3. View linked patients.
4. Review permitted patient adherence information.
5. Verify caregiver data access.

### Admin

1. Sign in as an admin.
2. Open the admin dashboard.
3. Review administration features.
4. Open OCR monitoring.
