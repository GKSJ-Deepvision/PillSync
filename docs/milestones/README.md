# Milestone reports

Fill in one template per milestone, on your own branch, and commit it before the
milestone deadline. CI checks that the file for the current milestone exists and
that the placeholders have been replaced.

| Milestone | Weeks | Template |
|---|---|---|
| 1 — Requirements, Database Design & Core Setup | 1–2 | `milestone-1.md` |
| 2 — Medication Management & Reminder System | 3–4 | `milestone-2.md` |
| 3 — OCR Recognition & Refill Prediction | 5–6 | `milestone-3.md` |
| 4 — Analytics, Testing & Deployment | 7–8 | `milestone-4.md` |
